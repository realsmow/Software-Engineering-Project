## Checklist ของสัญญา

<!-- ข้อที่ compiler จับให้ไม่ได้ ต้องใช้คนตอบ -->

- [ ] ทุก `@Query`/`@Mutation` ที่เพิ่ม/แก้ มีทั้ง `input` **และ** `output` schema
      <br><sub>ลืม `output` = frontend ได้ `any` = ทุกอย่าง compile ผ่านโดยไม่มีการตรวจสอบเหลืออยู่เลย</sub>
- [ ] ไม่มี procedure ไหน `return` Prisma model ตรง ๆ
      <br><sub>`AccountInfo` มี `HashedPassword` อยู่ในตารางเดียวกับชื่อและอีเมล</sub>
- [ ] สถานะที่ส่งออกเป็นสตริงคงที่ ไม่ใช่เลข primary key
- [ ] เวลาที่ส่งออกเป็นสตริง ISO ใน UTC ไม่มีข้อยกเว้น
- [ ] รัน `npm run sync:contract` แล้ว และ commit ไฟล์สัญญาที่อัปเดตไปด้วย
- [ ] `tsc --noEmit` ผ่านทั้ง `frontend/` และ `backend-preview/backend/`

## ถ้าเป็น procedure ใหม่

- [ ] ระบุ role ที่เรียกได้ และผูก middleware ตรงกับที่ระบุใน `CONTRACT.md` แล้ว
- [ ] รหัส error ทางธุรกิจที่เป็นไปได้ อยู่ใน `error-codes.ts` แล้ว
      และ `error-messages.ts` ฝั่ง frontend มีข้อความรองรับแล้ว
- [ ] ถ้าเป็น **mutation** - ระบุแล้วว่าต้อง `invalidate` query ตัวไหนบ้าง
- [ ] ถ้าเป็น **query ที่ polling** - ระบุความถี่ และตรวจแล้วว่า output ไม่ใหญ่เกินจำเป็น
