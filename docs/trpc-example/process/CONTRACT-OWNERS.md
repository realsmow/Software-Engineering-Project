## 2. การเปลี่ยนสัญญาสี่ชนิด

| ชนิด | ตัวอย่าง | ต้องทำอะไร |
|---|---|---|
| เพิ่มฟิลด์ที่ไม่บังคับ | เพิ่ม `note?` ใน output | แจ้งในช่องทางกลาง ไม่ต้องรออนุมัติ |
| เพิ่ม procedure ใหม่ | เพิ่ม `loan.extend` | แจ้ง + เพิ่มแถวใน `CONTRACT.md` |
| **เปลี่ยนชื่อ / ลบฟิลด์ / เปลี่ยนชนิด** | `dueAt` → `dueDate` | **คุยกับอีกฝั่งก่อน** และแก้พร้อมกันใน PR เดียว |
| **เปลี่ยนความหมายโดยรูปร่างเหมือนเดิม** | `status: 'pending'` เดิมนับ "รอรับของ" ด้วย เปลี่ยนเป็นสถานะแยก | **อันตรายที่สุด** — compiler จับไม่ได้ ต้องคุย + ต้องมีคนทดสอบ |

แถวล่างสุดคือชนิดที่ระบบ type ช่วยอะไรไม่ได้เลย จึงต้องใช้กระบวนการของคนล้วน ๆ
