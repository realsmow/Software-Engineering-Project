## สไลด์ 11 — หลักฐานการเรียก API จริง (เก็บ 9 ก.ย.)

รายงานครั้งที่ 2 (4 ก.ย.) เคยจัดวงจรยืม–คืน การอนุมัติ และการแจ้งเตือนไว้ที่ระดับ
**"เขียนเสร็จ ยังไม่พิสูจน์"** สไลด์นี้คือหลักฐานที่ปิดช่องว่างนั้น เก็บ 9 ก.ย. บน `e9dd276`
รายงานครั้งที่ 3 จึงยกแถวนั้นขึ้นเป็น "พิสูจน์แล้ว แต่ไม่อัตโนมัติ" (สไลด์ 10)
**ยังไม่ครอบคลุมการต่ออายุ** ซึ่งเข้า main หลังวันเก็บหลักฐาน

ทุกแถวในตาราง call log และตัวเลข cron job มาจากการยิง HTTP จริงเข้าเซิร์ฟเวอร์
ที่คอมไพล์จากโค้ดบน `origin/main` (ไม่ใช่เรียกฟังก์ชันในโปรเซสเดียวกัน) บนฐานข้อมูล
PostgreSQL ที่สร้างใหม่ ผ่าน migration ของโปรเจกต์เอง แล้ว seed ด้วย `prisma/seed.ts`
**ไม่มีข้อมูลจำลองหรือค่าพิมพ์มือ** ทำซ้ำได้ด้วยขั้นตอนนี้ (ต้องมี Docker + Postgres):

```bash
cd backend
docker exec <container-postgres> psql -U <user> -c "CREATE DATABASE ulms_evidence"
DATABASE_URL=postgresql://<user>:<pass>@localhost:<port>/ulms_evidence npx prisma migrate deploy
DATABASE_URL=postgresql://<user>:<pass>@localhost:<port>/ulms_evidence node dist-tools/prisma/seed.js
# แล้วสร้างบัญชี supervisor.demo@ku.th และ admin.demo@ku.th เพิ่มเอง (seed มีแค่ staff/student)
# สตาร์ตเซิร์ฟเวอร์ที่คอมไพล์แล้วบนพอร์ตว่าง แล้วยิงสคริปต์เรียก tRPC ผ่าน HTTP จริง
```

ถ้ารันโค้ด backend รุ่นใหม่กว่านี้แล้วตัวเลขไม่ตรง (เช่น cron job เพิ่มขึ้นจาก 5/8)
ให้เก็บหลักฐานใหม่ทั้งชุดและแก้ `EVIDENCE_SOURCE` / `API_EVIDENCE` / `CRON_*` ใน
`progress_data.py` ไม่ใช่แก้ตัวเลขในโค้ดวาด

## สองข้อตกลงของเด็คนี้ — อย่าเผลอใส่กลับ

**ไม่มีหัวข้อ "ข้อจำกัดที่เหลือ" บนสไลด์ผลงาน** เด็คนี้เล่าเฉพาะผลงานที่ส่งมอบแล้ว
ข้อจำกัดยังอยู่ครบในรายงาน `progress-report-03.tex` ใต้ผลงานแต่ละฝั่ง — ถ้าอาจารย์ถาม
ระหว่างนำเสนอให้เปิดรายงานตอบ ไม่ต้องเติมกลับเข้าสไลด์
(ข้อยกเว้นเดียวที่มีมาตั้งแต่ครั้งที่ 1 คือคอลัมน์เครื่องมือในสไลด์ 09 ซึ่งข้อจำกัดคือ
สถานะของตัวระบบตรวจเอง ไม่ใช่ของงานที่ส่งมอบ)
สิ่งที่ยังไม่ผ่านของรอบนั้น ๆ ไปอยู่ในสไลด์ทบทวน (05) คอลัมน์ "สภาพจริง" แทน —
รอบที่ 3 ข้อถดถอยของปุ่มส่งคำขอจึงอยู่ที่นั่น ไม่ใช่บนสไลด์ Front-End

**สไลด์ระดับหลักฐาน (10) เริ่มมีในครั้งที่ 2** แยก "เขียนโค้ดเสร็จ" ออกจาก
"มีอะไรพิสูจน์แล้ว" — ไม่ใช่รายการข้อจำกัด แต่เป็นการบอกว่าตัวเลข % วัดอะไร
ถ้าไม่ต้องการ ลบบรรทัด `("10-evidence-level", slide_evidence)` ใน `SLIDES` ออกได้

**ไม่ใช้จุดคั่น `·` ในข้อความที่ขึ้นสไลด์** คั่นวลีด้วยการเว้นวรรค หรือใช้คำเชื่อม
("และ" / "พร้อม") แทน ถ้าเว้นวรรคแล้วอ่านกำกวมให้เขียนคำเชื่อมลงไป อย่ากลับไปใช้จุด
(จุดที่ยังเหลือใน `.py` เป็นคอมเมนต์กับเส้นคั่นหัวข้อในโค้ด ไม่ได้ขึ้นสไลด์)

**หน้าปกตัดทิ้งได้** ถ้าเอาไปแปะต่อในเด็คที่มีปกอยู่แล้ว — ลบ `00-cover.svg` ทิ้งอย่างเดียวพอ
ไฟล์อื่นไม่ได้อ้างถึงกัน

## การตัดบรรทัดภาษาไทย

ภาษาไทยไม่มีช่องว่างระหว่างคำ **สไลด์ตัดบรรทัดได้เฉพาะตรงที่เว้นวรรคไว้เองใน
`progress_data.py`** เวลาเขียนคำบรรยายจึงต้องเว้นวรรคตามวลี ไม่ใช่ตามความสวยของ
บรรทัดในไฟล์ ถ้าลืมเว้น ข้อความจะถูกตัดกลางคำเป็นทางสุดท้าย (ดู `_split_token`)

ความกว้างวัดจาก advance width จริงของฟอนต์ผ่าน `text_metrics.py` ไม่ใช่เดาจากจำนวน
ตัวอักษรแบบ `thai_w()` ใน `slide_theme.py` — **ต้องมี Pillow ที่มี Raqm** ไม่งั้นสระบนล่าง
กับวรรณยุกต์จะถูกนับความกว้างเกินจริง แล้วบรรทัดจะสั้นกว่าที่ควร ตรวจด้วย

```bash
python3 -c "from PIL import features; print(features.check('raqm'))"
```

## PNG บนเครื่องนี้

`rsvg-convert` (แพ็กเกจ `librsvg2-bin`) **ไม่ได้ติดตั้ง** ชุดนี้จึงใช้ `svg_to_png.py`
ซึ่งเรียก librsvg ผ่าน GObject Introspection แทน ตัวเรนเดอร์เป็นตัวเดียวกันจึงได้ผลเหมือนกัน
ส่วน `slide_theme.rasterize()` ที่อีกสองชุดใช้ยังต้องการไบนารีอยู่ (ไม่ได้แก้ ของเดิมยังทำงานได้ถ้าลงเพิ่ม)

## ฟอนต์ตอนอัปเข้า Canva

SVG อ้างฟอนต์ **Laksaman** กับ **DejaVu Sans Mono** ถ้า Canva ไม่มี จะถูกแทนด้วย
ฟอนต์อื่นแล้วระยะห่างจะเพี้ยน (ตำแหน่งทุกอย่างคำนวณจากความกว้างของฟอนต์จริง)
**ถ้าไม่ตั้งใจจะแก้ข้อความต่อใน Canva ให้อัป `.png` แทน จะตรงตามที่ออกแบบไว้เสมอ**

## แผนที่รวม (`00-map`)

สไลด์เดียวเห็นทั้งฐานข้อมูล ใช้เปิดหัวข้อก่อนเจาะเข้าสไลด์ 01–09 — กล่องหนึ่งกล่องคือ
หนึ่งกลุ่มพร้อมรายชื่อตารางในกลุ่ม เส้นคือความสัมพันธ์ **ระดับกลุ่ม**

**ทำไมถึงเป็นระดับกลุ่ม ไม่ใช่ระดับตาราง** — รอบแรกวาด FK รายตารางครบทั้ง 58 เส้น
แล้วอ่านไม่ออก เส้นพันกันจนตามไม่ทัน พอยุบคู่ที่อยู่กลุ่มเดียวกันทิ้ง (22 เส้น เพราะ
สไลด์ย่อยของกลุ่มนั้นวาดให้แล้ว) เหลือ **22 เส้นระหว่างกลุ่ม** จาก FK 36 เส้น
ความหนาของเส้นและตัวเลขในวงกลมบอกว่าคู่นั้นเชื่อมกันด้วย FK กี่เส้น

กล่องวางบนตาราง **4 คอลัมน์ × 3 แถว เรียงตามเลขกลุ่ม 01→09** ซึ่งเป็นลำดับเดียวกับ
สไลด์ที่จะพูดต่อ พอเทียบผังที่เป็นไปได้แล้วผังนี้ให้เส้นรวมสั้นกว่าผัง 2×5 ที่ล็อกตาม
lifecycle ราว 20% ด้วย (ผังที่เครื่องจัดเองอิสระสั้นกว่านี้อีก แต่สลับลำดับกลุ่มจนเล่าไม่ได้)
ตำแหน่งอยู่ที่ `slot` ใน `schema_data.py` ส่วน `map_order` คุมลำดับชื่อตารางในกล่อง

## วิธีอ่านการ์ด

- ป้าย **PK** สีทอง = Primary Key · ป้าย **FK** ขอบสีเน้น = Foreign Key
- **เส้นโค้ง** = FK ที่ชี้ไปตารางอื่น *ในกลุ่มเดียวกัน* (จุดออกที่ฟิลด์ → หัวลูกศรที่ตารางปลายทาง)
- **`→ ชื่อตาราง`** สีเทาหลังชื่อฟิลด์ = FK ที่ชี้ออกไป *นอกกลุ่ม* วาดเส้นในสไลด์นี้ไม่ได้
