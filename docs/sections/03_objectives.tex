\section{วัตถุประสงค์ (Objectives)}

\begin{itemize}
  \item เพื่อพัฒนาระบบที่ให้นักศึกษาสามารถค้นหาและขอยืมอุปกรณ์ผ่านช่องทางออนไลน์ได้
  \item เพื่อให้สามารถบริหารจัดการคำขอยืม อนุมัติ/ปฏิเสธ และติดตามการคืนอุปกรณ์ได้อย่างเป็นระบบ
  \item เพื่อให้ผู้ใช้งานทราบสถานะและจำนวนคงเหลือของอุปกรณ์แต่ละชิ้นแบบเรียลไทม์
  \item เพื่อลดปัญหาการสูญหายและการคืนอุปกรณ์ล่าช้า ด้วยระบบแจ้งเตือนและการติดตาม
  \item เพื่อจัดเก็บประวัติและข้อมูลสถิติการใช้งานสำหรับสนับสนุนการตัดสินใจในการจัดการอุปกรณ์
  \item เพื่อออกแบบและพัฒนาระบบให้มีสถาปัตยกรรมครบทั้ง 4 ส่วน (Client, Application Server, API Server, Database Server) ตามข้อกำหนดของโครงการ
\end{itemize}
