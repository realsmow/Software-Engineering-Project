\section{เป้าหมาย (Goals)}


\begin{itemize}
  \item ระบบรองรับผู้ใช้งานหลายบทบาท (นักศึกษา, เจ้าหน้าที่ผู้ดูแลอุปกรณ์, อาจารย์, ผู้ดูแลระบบ) ให้สามารถทำงานร่วมกันได้
  \item ระบบจัดการบัญชีรายการอุปกรณ์ได้ครบถ้วน
  \item มีกระบวนการยืม–คืนครบวงจร ตั้งแต่ส่งคำขอ อนุมัติ รับของ คืนของ จนถึงตรวจสอบสภาพ
  \item มีระบบแจ้งเตือนและติดตามผ่าน Email รวมถึงการแจ้งเตือนภายในแอป
  \item มี Dashboard และรายงานสรุปสถิติการใช้งานอุปกรณ์
  \item ออกแบบสถาปัตยกรรม 4 ส่วน โดยมี API Server แยกการทำงานออกจาก Database Server อย่างชัดเจน
\end{itemize}
