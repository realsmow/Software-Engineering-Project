# API reference

> Generated by `npm run docs:api` from the router decorators.
> Do not edit by hand - re-run the script instead.

**8 routers, 74 procedures.**

Transport is tRPC over HTTP at `/trpc`, not REST, so there is no OpenAPI
document: the contract is the TypeScript router type, checked at compile
time on both sides. This page is the human-readable view of it.

Access is enforced by middleware on every procedure. `public` means no
session is required; everything else rejects an anonymous caller with
`NOT_AUTHENTICATED` and a wrong-role caller with `ROLE_NOT_ALLOWED`.
