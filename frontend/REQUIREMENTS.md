# Requirements

Static front-end. **No package manager, no dependencies to install.** It runs
in a browser as-is.

## To view / run

- Any modern browser — Chrome, Firefox, Edge, or Safari (last 2 years)
- *(optional)* Python 3 — only if you want a local server:
  `python3 -m http.server 8000`
- Internet connection — only to load the Sarabun font from Google Fonts.
  Offline still works; text falls back to the system font.

## To edit

- A text editor. That's it. No build, no compile, no `npm install`.

## Not required

No Node, npm, React, bundler, or backend to open this front-end. There is no
`package.json` because there are no JS package dependencies — everything (CSS,
JS, icons) is inline in the single HTML file.
